## Workflow Description

1. Load contacts from Excel.
2. Read the message template.
3. Launch Microsoft Edge.
4. Connect Selenium to Edge.
5. Open WhatsApp Web.
6. Authenticate if required.
7. Search for each contact.
8. Send the predefined message.
9. Record success or failure.
10. Retry failed contacts.
11. Generate final execution logs.
